# 네오클라우드 인사이트 📊

오라클·코어위브·네비우스·아이렌 등 **네오클라우드(AI 인프라) 기업**을 추종하는
투자자용 모바일 대시보드입니다. Toss 스타일의 심플·클린한 UI로, 핵심 지표와
실시간 뉴스를 한 화면에서 빠르게 파악할 수 있습니다.

## ✨ 주요 기능

- **홈 대시보드** — 회사별 카드(주가·등락률·수주잔고·확보용량), 미니 스파크라인,
  섹터 합산 요약. 등락률/수주잔고/확보용량 기준 정렬.
- **비교** — 시간(X축) 대비 **수주잔고($B)** 또는 **확보 용량(GW)**(Y축) 추이를
  여러 회사 겹쳐서 비교. 현재값 랭킹 바 차트 포함.
- **실시간 뉴스** — Google News에서 회사별/섹터 최신 헤드라인을 자동 검색
  (API 키 불필요).
- **종목 상세** — 기업 소개, 핵심 지표, 분기별 추이 차트, 주가 촉매·리스크,
  주요 고객, 실시간 뉴스.
- **관심종목** — 별표로 담아두면 한곳에 모아보기(localStorage).

> 한국 증시 관례에 맞춰 **상승=빨강, 하락=파랑**으로 표시합니다.

## 🚀 실행

```bash
npm install
npm run dev
# http://localhost:3000
```

빌드:

```bash
npm run build && npm start
```

## 🧱 기술 스택

- **Next.js 14** (App Router) + **React 18** + **TypeScript**
- **Tailwind CSS** (Toss 팔레트), **Pretendard** 폰트
- **Recharts** (비교 차트)
- 서버 API 라우트로 실시간 데이터 조회 (외부 키 불필요)

## 🔌 데이터 출처

| 데이터 | 출처 | 비고 |
| --- | --- | --- |
| 주가·등락률 | `/api/quote` → Yahoo Finance | 60초마다 갱신, 실패 시 폴백가 |
| 뉴스 | `/api/news` → Google News RSS | 회사명/섹터 키워드 검색 |
| 수주잔고(RPO)·확보용량(GW) | `lib/data.ts` 큐레이션 | 실적발표·공시 기반(참고용) |

수주잔고와 전력·용량 데이터는 공개 API로 제공되지 않아, 실적발표/공시를 토대로
`lib/data.ts`에 직접 큐레이션했습니다. **분기 실적이 나올 때마다 해당 파일의
시계열만 갱신**하면 차트가 자동 반영됩니다.

## 🏢 추종 기업 추가/수정

`lib/data.ts`의 `COMPANIES` 배열에 객체를 추가하면 모든 화면(홈/비교/뉴스/상세)에
자동 반영됩니다. 티커(`symbol`)만 정확하면 실시간 주가·뉴스가 연결됩니다.

## ⚠️ 면책

본 앱의 모든 수치는 참고용이며 투자 권유가 아닙니다. 큐레이션된 수주잔고·용량
값은 실제와 차이가 있을 수 있으니, 투자 판단 전 원문 공시를 확인하세요.
